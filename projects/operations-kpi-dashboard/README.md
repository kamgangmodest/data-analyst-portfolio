# Operations KPI Dashboard

## Business Question
Where is work accumulating, which teams are at risk of missing SLA, and what operational patterns should leadership address first?

## Tools
SQL • Power BI / Tableau

## KPIs
- Received workload
- Completed workload
- Open backlog
- SLA / on-time %
- Average aging
- Reopen / exception rate
- Productivity by team
- Aging buckets

## Business Value
Designed to surface leading indicators before monthly SLA performance is missed.
