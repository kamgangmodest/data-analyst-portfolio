# SaaS Revenue & RevOps Analytics

## Project Overview
A synthetic **finance / revenue / business analytics** project focused on pipeline health, closed-won ARR, win rate, deal size, sales-cycle efficiency, customer segment performance, and acquisition-source effectiveness.

## Tools
**SQL • Revenue Analytics • RevOps • Power BI Concepts • KPI Development • Business Storytelling**

## Executive KPIs
| KPI | Result |
|---|---:|
| Closed-Won ARR | **$2,832,969** |
| Open Pipeline | **$1,430,020** |
| Win Rate | **44.0%** |
| Average Deal Size | **$11,023** |
| Average Sales Cycle | **51 days** |

## Key Findings
- **Enterprise** is the top segment by closed-won ARR.
- **Event** is the top acquisition source.
- Enterprise opportunities carry higher value but longer cycle times.
- Win rate and pipeline quality should be reviewed together.
