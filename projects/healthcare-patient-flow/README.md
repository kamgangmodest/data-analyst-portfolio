# Healthcare Patient Flow Analysis

## Business Question
How can hospital leaders monitor patient flow, capacity, and utilization to identify bottlenecks and improve operational visibility?

## Tools
SQL • Power BI

## KPIs
- Admissions
- Discharges
- Active census
- Average length of stay
- Readmission rate
- Bed occupancy
- Service / unit volume
- Daily and monthly trends

## Important
Use synthetic or public healthcare data only. Never publish PHI, patient-level employer data, or proprietary schemas.
