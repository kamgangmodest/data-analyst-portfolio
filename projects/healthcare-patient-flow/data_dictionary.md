# Data Dictionary

| Column | Description |
|---|---|
| encounter_id | Synthetic encounter identifier |
| patient_id | Synthetic patient identifier |
| admit_datetime | Admission date/time |
| discharge_datetime | Discharge date/time |
| unit_name | Hospital unit |
| bed_capacity | Synthetic staffed bed capacity |
| admission_source | Admission source |
| payer | Payer category |
| age | Synthetic patient age |
| length_of_stay_days | Length of stay in days |
| readmit_30d | 30-day readmission indicator |
| discharge_disposition | Discharge destination |

All records are synthetic and contain no PHI.
